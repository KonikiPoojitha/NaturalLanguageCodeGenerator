# Natural Language Code Generator

A Python-based AI application that converts natural language instructions into Python code using the Groq API.

## Features

- Generate Python code from natural-language instructions
- Interactive command-line interface
- Uses Groq AI for code generation
- Secure API key management using `.env`
- Supports multiple coding requests in one session

## Tech Stack

- Python
- Groq API
- python-dotenv
